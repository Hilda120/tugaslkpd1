Menurutmu, bagaimana cara menyimpan informasi tersebut di dalam program? Tuliskan dugaanmu:

Jawaban:
Informasi tersebut dapat disimpan menggunakan variable pada JavaScript. Setiap data diberi nama tempat (identifier) seperti let namaSiswa = "Hilda Maulida" atau let umur = 16, sehingga data tersimpan di memori komputer dan bisa dipanggil atau diperbarui kapan saja oleh program.

E. AKTIVITAS 1 – MENGAMATI

Perhatikan kode JavaScript berikut:

let nama = 'Budi';
let umur = 16;
let nilai = 85;

console.log(nama);
console.log(umur);
console.log(nilai);

Hasil console

Pertanyaan:

  1. Apa yang ditampilkan pada Console?
    Budi
    16
    85
  2. Menurutmu, apa fungsi nama, umur, dan nilai?
    Sebagai nama variable (wadah) untuk menyimpan nilai/data seperti nama teks 'Budi', angka umur 16, dan angka nilai 85.
  3. Apa yang terjadi jika kode berikut dijalankan? console.log(nama);
    Program akan menampilkan isi dari variable nama yaitu teks "Budi" pada console.
  4. Menurut dugaanmu, apa yang dimaksud dengan variable?
    Variable adalah wadah/tempat di memori komputer yang digunakan untuk menyimpan data agar dapat diproses, diubah, atau dipanggil kembali oleh program.

F. AKTIVITAS 2 – MEMAHAMI STRUKTUR VARIABLE

Dalam sintaks let nama = 'Andi'; terdapat komponen:

  • let : Kata kunci untuk membuat variable.
  • nama : Nama variable (identifier).
  • = : Operator pengisian nilai (assignment).
  • 'Andi' : Nilai yang disimpan di dalam variable.

J. AKTIVITAS 6 – MENGENAL let DAN const

Amati dua contoh kode berikut:

Kode 1:

let umur = 16;
umur = 17;
console.log(umur); // Output: 17

Kode 2:

const nama = 'Budi';
nama = 'Andi'; // Error!
console.log(nama);

Kesimpulan Perbedaan let dan const:

Keyword Nilai dapat diubah? Kegunaan Sederhana
let Ya Digunakan untuk data yang nilainya dapat berubah-ubah saat program berjalan.
const Tidak Digunakan untuk data konstan yang nilainya tetap dan tidak boleh diubah.

Q. AKTIVITAS 13 – THINK PAIR SHARE

Pertanyaan: Menurutmu, mengapa programmer membutuhkan variable?

Jawaban:
Programmer membutuhkan variable untuk menyimpan data secara dinamis di memori komputer. Tanpa variable, data tidak dapat diolah, disimpan, dihitung, atau digunakan kembali di bagian program lainnya. Variable membuat program menjadi fleksibel dan efisien.

T. KESIMPULAN

  • Variable adalah: tempat/wadah di dalam memori komputer yang digunakan untuk menyimpan data.
  • let digunakan untuk: membuat variable yang nilainya masih dapat diubah/diperbarui saat program berjalan.
  • const digunakan untuk: membuat variable yang nilainya tetap (konstan) dan tidak dapat diubah kembali.
  • Untuk menampilkan isi variable ke Console kita dapat menggunakan: perintah console.log().
